## 🚀 A. 有料化で「明日すぐ」着火できること

### A-1. WordPress有料化（Businessプラン相当を想定）
| 施策 | 効果 | 誰が |
|---|---|---|
| **Yoast SEO / Rank Math導入** | タイトル・メタディスクリプション最適化、リッチリザルト（FAQ構造化データ）でCTR向上。今のGoogle検索結果は素の抜粋しか出ていない | 私が導入・全記事に設定を書けます |
| **広告バナー非表示** | 現在、訪問者に「アップグレードしてバナーを削除」というWP純正広告が出ている。CVRを直接下げている要因 | 有料化で自動解消 |
| **カスタムドメイン取得** | `treecosme.home.blog` → `treecosme.com`等の独自ドメインへ。ブランド信頼性・SEO評価が上がる。名刺やSNSプロフィールにも使える | ゆうさんがドメイン選定→私が設定作業 |
| **サイト表示速度プラグイン** | ページ速度はGoogleのランキング要因。特にAmazon画像を多用した物販記事で効く | 私が導入 |
| **リダイレクト管理プラグイン** | 記事タイトル変更時のURL変化に301リダイレクトを設定でき、SEO評価を失わない | 私が導入・設定 |

**インパクト最大**：Yoast導入＋広告除去＋独自ドメイン。この3つだけで「検索結果の見え方」「訪問者の第一印象」「CVR」が同時に改善します。

### A-2. n8n有料化（Activate常時稼働が可能に）
CLAUDE.mdの「完全無人投稿禁止」は維持した上で、**読み取り・分析・下書き準備**を自動化：

| ワークフロー | 内容 | 承認制ルール適合 |
|---|---|---|
| **DEV_RIO_401 Metrics Ingestion（既存設計あり）** | Gumroad/Threads/note/Brain/ASPの売上・PVを毎日自動収集→ダッシュボード化 | ✅ 読み取りのみ、投稿なし |
| **検索順位・インデックス状況の自動監視** | Search Console APIで全記事の掲載順位・クリック数を毎日取得、下落記事をアラート | ✅ 読み取りのみ |
| **アフィリ提携承認の自動チェック（既存: affiliate_approval_checker）** | 新規承認された提携を検知し、Slack通知＋記事下書き候補をリストアップ | ✅ 通知・下書きのみ |
| **SNS投稿の「下書き作成→承認待ちキュー投入」自動化** | Threads/note送客ドラフトを毎日1本、承認待ちSlackチャンネルに自動投稿。ゆうさんがOKした分だけ手動/半自動で公開 | ✅ 最終公開は人間承認 |
| **価格・在庫変動監視（Amazon/楽天）** | 掲載商品の価格が下がった/セールになったらSlack通知→即座にSNS投稿案を作成 | ✅ 検知・下書きのみ |

**ここが肝**：n8nは「気づく・準備する」を無人化し、「公開する」は必ず人間が押す設計を維持します。これでCLAUDE.mdのルールを守りながら、ゆうさんの実作業時間を最小化できます。

## 📈 C. コンバージョン改善（記事の"1クリックの価値"を上げる）

- **FAQ構造化データ**：Yoast導入後、各記事の「よくある質問」をリッチリザルト化→検索結果で目立ち、CTR向上

## 🔧 検証結果メモ（無料プランの技術的制約）

- **JSON-LD構造化データ**：WordPress.com無料プランは `<script>` タグを本文から自動除去する。中身のJSONが生テキストとして表示される表示崩れを確認・削除済み。**Yoast等のSEOプラグイン導入（有料化後）でのみ実装可能**。
- **表の横スクロール対応（`overflow-x:auto`）**：無料プランのKSESフィルタが `overflow` 系CSSプロパティをインラインstyleから除去する。ただし `table-layout:auto` により長文セルは自動折り返しされるため、横にはみ出す致命的崩れは基本的に発生しない（実害は限定的と判断）。全24記事にmarginラッパーのみ適用済み（overflow効果はなし）。有料化後にYoast/カスタムCSS機能で正式対応可能。
