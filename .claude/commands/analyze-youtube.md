# /analyze-youtube

YouTube動画を実際にブラウザで開いて確認し、チャンネル戦略・動画構成・収益化設計を分析するSkill。

## 使い方

```
/analyze-youtube <YouTube URL> [または チャンネルURL]
```

URLなしで呼んだ場合は「分析したいYouTube URLを貼ってください」と聞く。

---

## 実行手順

### Step 1: ブラウザでページを開く

`mcp__claude-in-chrome__tabs_context_mcp` で現在のタブを確認後、新しいタブを作成して指定URLに遷移。

```
ToolSearch: select:mcp__claude-in-chrome__tabs_context_mcp,mcp__claude-in-chrome__tabs_create_mcp,mcp__claude-in-chrome__navigate,mcp__claude-in-chrome__read_page,mcp__claude-in-chrome__computer,mcp__claude-in-chrome__javascript_tool
```

### Step 2: 動画ページの情報を取得

`mcp__claude-in-chrome__read_page` でHTMLテキストを取得し、以下を抽出：

- タイトル
- チャンネル名・登録者数
- 視聴回数・いいね数
- 投稿日時
- 説明文（概要欄）全文
- ハッシュタグ
- コメント上位5件（ページをスクロールして取得）

### Step 3: 動画構成のスクリーンショット分析

`mcp__claude-in-chrome__computer` でスクリーンショットを取得。
動画を以下の時点で一時停止してスクリーンショットを撮る：
- 0〜5秒（フック）
- 中間（本編）
- ラスト（CTA・エンド）

`mcp__claude-in-chrome__javascript_tool` で動画の再生・一時停止を制御：
```javascript
// 動画を指定秒数にシーク
document.querySelector('video').currentTime = 3;
document.querySelector('video').pause();
```

## 複数動画を一括分析する場合

URLを複数渡すと順番に分析し、最後に比較表を出力する。

```
/analyze-youtube [URL1] [URL2] [URL3]
```

比較表フォーマット：
| 項目 | 動画1 | 動画2 | 動画3 |
|------|-------|-------|-------|
| 視聴回数 | | | |
| 尺 | | | |
| フック手法 | | | |
| CTA | | | |
| 収益化 | | | |
| 自分への応用 | | | |

---

## 注意事項

- YouTube動画の著作権コンテンツは再現・引用しない（スクショはレポート内部利用のみ）
- 動画の映像・音声そのものは分析の参考にするが、出力には含めない
- 分析中にポップアップ・広告が出た場合はスキップする（ダイアログ発生に注意）
