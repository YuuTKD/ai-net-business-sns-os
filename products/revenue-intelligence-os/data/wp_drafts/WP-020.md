# 初めてスタッフを雇うときの労務手続きチェックリスト｜労働契約・保険・給与まで一気に確認

初めてスタッフを雇うときにやることは、大きく分けて「**①労働条件の明示（契約）②労働保険（労災・雇用保険）③社会保険（該当する場合）④給与関係（税・給与計算）**」の4ブロックです。それぞれに提出先と期限が決まっており、知らずに放置すると後からまとめて是正することになります。

この記事では、美容室・カフェ・整体院など小規模店舗のオーナーが1人目のスタッフ（アルバイト含む）を雇う場面を想定して、チェックリスト形式で流れを整理しました。

## この記事で分かること

- 雇う前〜雇った直後にやる手続きの全体像と期限
- アルバイト1人でも必要になる手続きはどれか
- 自分でやるか、労務をアウトソースするかの判断基準

## ブロック①：労働条件の明示（雇う前〜初日）

- [ ] **労働条件通知書を交付する（義務）**
  契約期間・就業場所・仕事内容・労働時間・休憩・休日・賃金・退職に関する事項などを、書面（本人が希望すれば電子でも可）で明示する義務があります。厚生労働省がモデル様式を公開しているので、ゼロから作る必要はありません。
- [ ] **雇用契約書を交わす（強く推奨）**
  通知書は「渡す」だけですが、契約書は双方が署名するため「言った・言わない」を防げます。通知書と兼用の「労働条件通知書兼雇用契約書」の形が実務では一般的です。
- [ ] **最低賃金を確認する**
  時給は都道府県ごとの最低賃金以上に設定します。最低賃金は毎年改定されるため、募集時に最新額を確認してください。

## ブロック②：労働保険（アルバイト1人でも必要）

- [ ] **労災保険に加入する（1人でも雇えば原則加入義務）**
  「保険関係成立届」を、雇用した日の翌日から**10日以内**に労働基準監督署へ提出。あわせて「概算保険料申告書」を**50日以内**に提出・納付します。
- [ ] **雇用保険の加入要否を確認する**
  週の所定労働時間20時間以上、かつ31日以上の雇用見込みがあるスタッフは雇用保険の加入対象です。「雇用保険適用事業所設置届」と「被保険者資格取得届」をハローワークへ提出します（資格取得届は雇用した月の翌月10日まで）。
  短時間のアルバイトのみ（週20時間未満）の場合、雇用保険の被保険者にはなりませんが、労災保険は必要です。

## ブロック③：社会保険（健康保険・厚生年金）

- [ ] **自分の店が適用事業所かを確認する**
  法人であれば従業員数に関係なく強制適用です。個人事業の場合は、常時5人以上を雇う事業所で強制適用となる業種が定められている一方、飲食業・理美容業など一部のサービス業は5人以上でも任意適用とされています。ここは業種・形態で結論が変わるため、**年金事務所に自店のケースを確認するのが確実**です。
- [ ] **該当する場合は資格取得手続きを行う**
  適用事業所になる場合、「新規適用届」や従業員の「被保険者資格取得届」を年金事務所へ提出します（資格取得届は原則、雇用から5日以内）。

## ブロック④：給与関係（税・給与計算）

- [ ] **「給与支払事務所等の開設届出書」を税務署へ提出する**
  初めて給与を支払う事業者は、開設から**1か月以内**に提出します。
- [ ] **「扶養控除等（異動）申告書」をスタッフから回収する**
  源泉徴収税額の計算（甲欄・乙欄の判定）に必要です。最初の給与日までに回収します。
- [ ] **毎月の給与計算の体制を作る**
  勤怠集計 → 残業代（法定時間外は割増賃金）→ 社会保険料・雇用保険料・源泉所得税の控除 → 給与明細の交付、という流れを毎月回します。給与明細の交付は義務です。
- [ ] **法定三帳簿（労働者名簿・賃金台帳・出勤簿)を整備する**
  雇った時点から作成・保存義務があります。勤怠管理アプリや労務ソフトを使うと自動で揃いやすい部分です。

## その他、該当したら必要になるもの

- [ ] **36協定の届出**：法定労働時間（原則1日8時間・週40時間)を超える残業をさせる場合は、事前に労使協定（36協定)を労基署へ届け出る必要があります
- [ ] **就業規則**：常時10人以上を雇うようになったら作成・届出義務が発生します
- [ ] **健康診断**：常時使用する労働者には雇入時の健康診断が必要です

## 自分でやるか、外注するかの判断基準

1人目の採用時は、上記を1つずつ調べながらでも自力で完了できます。ただし次のような状態になったら、労務のアウトソースを検討するタイミングです。

- スタッフが複数人になり、入退社・保険手続きが繰り返し発生している
- 給与計算・年末調整に毎月まとまった時間を取られている
- 手続きの抜け漏れ（期限超過)が実際に起き始めている

## よくある質問

**Q. 家族（配偶者・親）に手伝ってもらう場合も同じ手続きが必要ですか？**
A. 同居の親族のみで営む場合、労災・雇用保険の扱いが一般の従業員と異なります。家族従業員のケースは判断が分かれやすいため、労基署・ハローワークに確認してください。

**Q. 試用期間中は保険に入れなくてもいいですか？**
A. いいえ。加入要件を満たすなら試用期間中でも加入が必要です。「試用期間だから未加入」は認められません。

**Q. 手続きを忘れていたことに後から気付いたら？**
A. 放置せず、さかのぼって手続きするのが原則です。自主的に是正する方が傷は浅いので、気付いた時点で提出先（労基署・ハローワーク・年金事務所)に相談してください。

## まとめ：4ブロック×期限で管理すれば怖くない

採用の労務手続きは、「契約」「労働保険」「社会保険」「給与」の4ブロックに分ければ全体像はシンプルです。期限があるもの（労災10日以内・給与支払事務所1か月以内など）から着手し、判断に迷う社会保険の適用は年金事務所へ確認。繰り返し発生するフェーズに入ったら、アウトソースで自分の時間を取り戻す——この順番で進めてみてください。
