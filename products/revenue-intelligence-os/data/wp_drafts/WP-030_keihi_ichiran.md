結論から言うと、経費にできるかどうかの判断基準はひとつだけです。**「その支出は、事業の売上を得るために直接必要だったか」**。国税庁は必要経費を「売上原価や、販売費・一般管理費など業務上の費用」と定義しており、あなたの手元のすべての支出は「①経費になる」「②経費にならない」「③一部だけ経費になる（家事按分）」の3つのどれかに必ず分けられます。

この記事では、開業1〜3年目の個人事業主・店舗オーナー向けに、経費になるもの・ならないものの一覧と、迷ったときに使える「3つの質問」による判断手順、そして記録を自動化する会計ソフト（やよいの青色申告オンライン・マネーフォワード クラウド会計）の使い方までを、国税庁の公開情報をもとに整理しました。読み終えるころには、溜まったレシートの束が「怖いもの」ではなくなっているはずです。なお、個別のケースの最終判断は税務署・税理士に確認してください。

<div style="background:linear-gradient(135deg,#00A4CC,#00D4FF);color:white;padding:14px 20px;border-radius:6px;font-size:20px;font-weight:bold;margin:32px 0 16px;">「あとで考えよう」のレシートは、静かにお金を減らしている</div>

引き出しやレジ横に、判断を保留したレシートの束が溜まっていないでしょうか。「この打ち合わせのカフェ代は経費でいいのか」「Amazonで買ったこの備品は？」と迷うたびに保留し、申告直前にまとめて悩む。開業から数年は、ほとんどの人がこの状態です。あなただけではありません。

問題は、保留したレシートの多くが「面倒だから計上しない」で終わることです。経費にできた支出を計上しなければ課税所得がそのぶん増え、払わなくてよかった税金を払うことになります。たとえば年間で15万円ぶんの経費を計上し忘れれば、その分がまるごと所得に上乗せされ、所得税・住民税・国民健康保険料まで連動して増えていきます。「ちりつも」で見過ごすには大きすぎる金額です。

逆に、基準を知らずに何でも経費に入れてしまうと、税務調査で説明できず修正を求められ、加算税・延滞税というペナルティを背負うリスクを抱えます。つまり「入れなさすぎ」も「入れすぎ」も、どちらも損。**そしてどちらの損も、判断基準を1回だけしっかり覚えれば避けられます。** 難しい簿記の知識は要りません。必要なのは、これから紹介する「3つの質問」を頭に入れることだけです。

<div style="border-left:4px solid #22c55e;background:#f0fdf4;padding:16px;margin:20px 0;border-radius:0 8px 8px 0;"><p style="font-weight:bold;color:#15803d;margin:0 0 8px;">✅ ポイント</p><p style="margin:0;">経費の判断で損をするのは「知らない」からではなく「判断を先延ばしにする」から。基準を1つ覚えれば、レシートを見た瞬間に3秒で仕分けられるようになります。</p></div>

<div style="background:linear-gradient(135deg,#00A4CC,#00D4FF);color:white;padding:14px 20px;border-radius:6px;font-size:20px;font-weight:bold;margin:32px 0 16px;">経費の大原則｜国税庁の定義と「3つの質問」</div>

![事業との関係を3つの観点から確認して経費を判断するイメージ](images/WP-030/img01.png)

国税庁のタックスアンサー（No.2210「やさしい必要経費の知識」）では、必要経費に算入できるのは次の2つとされています。

- 総収入金額に対応する売上原価など、収入を得るために直接要した費用
- その年に生じた販売費、一般管理費その他業務上の費用

要するに「事業に必要かどうか」がすべてです。金額の大小や、購入した店・支払い方法は関係ありません。判断の軸は「事業との関係性」だけ。迷ったら、次の3つの質問を順番に自分に投げかけてください。

<div style="border:2px solid #00A4CC;border-radius:8px;padding:20px;margin:20px 0;"><div style="background:#00A4CC;color:white;padding:6px 16px;border-radius:4px;display:inline-block;font-weight:bold;margin-bottom:12px;">STEP①</div><p style="margin:0;"><strong>その支出がなかったら、売上に影響したか？</strong><br>仕入・広告・打ち合わせなど、事業活動と直接つながっているかを確認します。「あってもなくても売上に関係ない」支出は、まず経費になりません。</p></div>

<div style="border:2px solid #00A4CC;border-radius:8px;padding:20px;margin:20px 0;"><div style="background:#00A4CC;color:white;padding:6px 16px;border-radius:4px;display:inline-block;font-weight:bold;margin-bottom:12px;">STEP②</div><p style="margin:0;"><strong>税務署の職員に、事業との関係を口頭で説明できるか？</strong><br>「誰と・いつ・何のために」をよどみなく言えるかがカギ。説明に詰まる支出は、証拠が足りないか、そもそも事業性が弱いサインです。</p></div>

<div style="border:2px solid #00A4CC;border-radius:8px;padding:20px;margin:20px 0;"><div style="background:#00A4CC;color:white;padding:6px 16px;border-radius:4px;display:inline-block;font-weight:bold;margin-bottom:12px;">STEP③</div><p style="margin:0;"><strong>事業と私生活が混ざっている場合、事業分を合理的に区分できるか？</strong><br>自宅家賃や携帯代のように公私混在する支出は、面積や使用時間など客観的な根拠で「事業分」を切り出せるかを確認します。区分できる部分だけが経費です。</p></div>

3つとも「はい」なら計上を検討でき、「いいえ」があれば入れない・または区分してから入れる、が基本です。この3ステップさえ身につければ、勘定科目の細かい分類に迷っても「そもそも経費になるかどうか」の入口で間違えることはなくなります。

<div style="border-left:4px solid #22c55e;background:#f0fdf4;padding:16px;margin:20px 0;border-radius:0 8px 8px 0;"><p style="font-weight:bold;color:#15803d;margin:0 0 8px;">✅ ポイント</p><p style="margin:0;">「領収書があるか」より「事業との関係を説明できるか」が本質。領収書は説明を裏づける証拠であって、領収書があれば何でも経費になるわけではありません。</p></div>

<div style="background:linear-gradient(135deg,#00A4CC,#00D4FF);color:white;padding:14px 20px;border-radius:6px;font-size:20px;font-weight:bold;margin:32px 0 16px;">経費になるものの一覧（勘定科目別・15科目）</div>

なお、1つ10万円以上の備品（パソコン・厨房機器など）は原則その年に全額を経費にできず、減価償却として数年に分けて計上します（国税庁タックスアンサーNo.2100）。青色申告者には30万円未満の資産を一括計上できる期限付き特例もあるため、要件・期限は国税庁サイトで確認してください。

<div style="border-left:4px solid #22c55e;background:#f0fdf4;padding:16px;margin:20px 0;border-radius:0 8px 8px 0;"><p style="font-weight:bold;color:#15803d;margin:0 0 8px;">✅ ポイント</p><p style="margin:0;"><strong>「経費にならない＝節税に使えない」ではありません。</strong> 国民健康保険・国民年金・生命保険料などは「所得控除」として確定申告で差し引けます。経費の欄に入れると誤りになる、ただ行き先（控除欄）が違うだけ、と覚えてください。会計ソフトなら控除欄への入力もガイド付きで進められます。</p></div>

<div style="background:linear-gradient(135deg,#00A4CC,#00D4FF);color:white;padding:14px 20px;border-radius:6px;font-size:20px;font-weight:bold;margin:32px 0 16px;">一部だけ経費になるもの｜家事按分の考え方</div>

![自宅と仕事場で共用する設備を事業用と私用に分けて考えるイメージ](images/WP-030/img03.png)

自宅で仕事をする人が最も迷うのが、家賃・電気代・通信費・車など事業と私生活の両方で使う支出（家事関連費）です。これらは**業務に直接必要だったことが明らかに区分できる部分に限って**経費にでき（国税庁タックスアンサーNo.2210）、この区分計算を一般に「家事按分」と呼びます。

上の割合はあくまで計算例で、「何%までならOK」という公式の一律基準はありません。大事なのは、**面積や時間など第三者に説明できる根拠で割合を決め、計算メモを残す**ことです。たとえば「間取り図で仕事部屋の面積を測り、全体に対する割合を出した」という一枚のメモがあれば、STEP②の「説明できるか」を余裕でクリアできます。逆に根拠なく「とりあえず50%」とするのは、質問2を満たせず危険です。迷う場合は税務署の相談窓口や税理士に確認するのが確実です。

経費の判断は「事業の売上のために直接必要だったか」がすべてで、支出は「なる・ならない・按分」の3つに分かれる——これが本記事の結論です。難しく考える必要はありません。

今日やることを1つだけ挙げるなら、**溜まったレシートを「事業」「私生活」「混ざっている」の3つの山に分けること**です。実際にやってみると、迷う支出は「混ざっている（按分）」の山に集中していると分かり、悩みの正体がはっきりします。そして記録を自動化したくなったら、会計ソフトの公式サイトでプランを確認してみてください。
