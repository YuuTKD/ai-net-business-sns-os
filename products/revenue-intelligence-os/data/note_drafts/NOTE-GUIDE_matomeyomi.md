# 【店舗オーナー向け】集客ノウハウ まとめ読みガイド｜SNS・口コミ・Googleマップ・見積・AI時短を一本化

一人〜少人数で店を回していると、集客の悩みは1つじゃありません。
SNSが続かない、口コミ返信が溜まる、Googleマップから来店に繋がらない、見積が失注する、雑務に時間を取られる——**これ全部、別々の問題に見えて、実は"店の見え方と手間"という一本の線でつながっています。**

このガイドは、その線をたどって**「今あなたの店でいちばん詰まっている1本」に最短で行ける道しるべ**です。
下の「こんな悩みがある人へ」から、当てはまるものを選んでください。それぞれの解決記事に、そのまま使えるテンプレ・チェックリスト・AI指示文が入っています。

> このガイド自体は無料です。各記事は、実際に手を動かす部分（テンプレ・手順・チェックリスト）が有料になっています。まず気になる1本から、無料エリアを読んでみてください。

### 💴 見積・問い合わせで失注する

## おすすめの読む順番（＝つまずきが減る順）

集客は「見つかる→伝わる→来店→対応→リピート」の順で効きます。全部やる必要はありませんが、迷ったらこの順に1本ずつ潰すのが最短です。

1. **見つかる**：NOTE-006 / NOTE-010（Googleマップ）
2. **伝わる**：NOTE-004（SNS発信）/ NOTE-011（プロフィール・入口）
3. **来店・対応**：NOTE-005（口コミ）/ NOTE-008・009（見積）
4. **時間を作る**：NOTE-007（AI時短）＋ NOTE-012（AIプロンプト集）で、上のぜんぶを毎週の作業に落とし込む

> **セットで効く組み合わせ**
> - 発信を立て直すなら → **004＋005＋012**（投稿の型＋口コミ返信＋AI指示文）
> - Googleマップから来店を増やすなら → **006＋010**
> - 問い合わせを受注に変えるなら → **008＋009**
> どれも「1本ずつ」でも効きますが、隣の1本と合わせると"抜け"がなくなります。
