# 業種別チューニング｜同じプロンプトを、あなたの業種に最適化する

同じプロンプトでも、業種で「触れるべきポイント」が変わります。マスターシートの"トーン"欄と合わせて意識してください。

- **美容室・サロン**：仕上がり・居心地・担当者の人柄に触れると刺さる。効果を断定せず「なりたい印象に近づく」など"変化"は控えめに（景表法・美容表現に注意）。
- **飲食店・カフェ・バー**：味だけでなく"シーン"（一人で／仲間と／記念日に）を描くと保存されやすい。酒類は媒体の広告ポリシーを確認。
- **整体・治療院・ボディケア**：「治る」「改善する」等の効果保証は避け、「セルフケアの一助」「リラックス」など事実の範囲で。医療的判断は専門家へ、を添える。
- **物販・EC・小売**：使用シーン・アフターケア・他商品との合わせ方に触れると単価が上がる。在庫・価格は変動前提で断定しない。

**共通の鉄則**：マスターシートの「使わない言葉」に、業種のNG表現（誇大・効果保証・最上級）を入れておくと、AIが自動で避けてくれます。

# 週30分で回す、AI運用ルーティン

プロンプトは"持っているだけ"では意味がありません。週に1回、30分の枠を固定して、文章仕事を仕組みにします。

1. **0〜5分**：先週の口コミ・DM・コメントを一覧で確認（未返信をリスト化）
2. **5〜15分**：口コミ・DM返信を、該当プロンプト＋マスターシートでまとめて下書き→1〜2箇所だけ自分の言葉に直して送信
3. **15〜25分**：今週のSNS投稿を、㊿（ネタ出し）→各プロンプトで3〜4本下書き。予約投稿に入れる
4. **25〜30分**：来週の予定（キャンペーン・イベント・空き枠）を確認し、必要な告知文を1本だけ先に用意

**ポイント**：毎日ちょこちょこやると集中力が削られます。**週1バーストでまとめて片付ける**方が、質も速度も上がります。慣れれば30分で1週間分が回ります。

# よくある失敗と対処｜AIが"事故る"典型パターン

- **失敗1：そのまま貼って他人行儀**／対処：マスターシートを必ず先に貼る＋出力を1〜2箇所自分の言葉に直す。
- **失敗2：存在しない情報をAIが創作（料金・実績・在庫）**／対処：プロンプトに「入力にない情報は作らない」を足す。公開前に必ず事実を目視確認。
- **失敗3：誇大・断定表現が混じる**／対処：マスターシートの「使わない言葉」に「絶対／必ず／最安／No.1／治る」等を登録。
- **失敗4：長すぎて読まれない**／対処：SNS・DMは出力を2〜3割削る。「◯字で」と指定しても長めに返るので、最後に手で詰める。
- **失敗5：ネガティブ対応で感情が出る**／対処：クレーム系は"送信前に一晩置く"を習慣に。AIの冷静な下書きは、その一晩の代わりにもなります。

# この50本を"応用"する｜自分専用プロンプトの作り方

この大全のプロンプトは、すべて同じ骨組みでできています。この型を覚えれば、載っていない場面でも自分で作れます。

```
①役割：「（マスターシートの）店のオーナー/SNS担当として」
②目的：何のための文章か（例：来店を促す／不安を消す）
③制約：文字数・トーン・入れる要素・入れない要素
④材料：【　】で埋める、その場面固有の情報
⑤禁止：事実の創作・誇大・断定をしない
```

たとえば「取材依頼への返信」が必要になったら、①〜⑤に当てはめるだけ。**プロンプトは"覚える"ものではなく"組み立てる"もの**——この型が、この大全をあなたの店専用に無限に広げます。

# "自分の店らしく"仕上げる5つのコツ

1. **マスターシートを毎回貼る**：これだけで出力の"店らしさ"が段違いになります。
2. **一人称と口ぐせを1つ足す**：「〜ですね」「ぜひ」など普段の言葉を1箇所入れる。
3. **固有名詞を1つ入れる**：メニュー名・スタッフ名・地域名など、AIが知らない情報でテンプレ感が消える。
4. **長さを削る**：AIは丁寧に書きすぎる。SNS・DMは2〜3割削るとちょうどよい。
5. **1箇所"わざと崩す"**：完璧すぎる敬語より、少し崩れた一言のほうが人間味が出て返信されやすい。
