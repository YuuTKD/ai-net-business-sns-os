# 楽天ROOM ローンチキット（実行の先回り／店舗オーナー特化）

作成: 2026-08-09
位置づけ: `rakuten_room_strategy.md`（5コレクション設計・テンプレ）を**そのまま実行できる形**に落とした手順書。
  ゆうさんのバースト手作業を「楽天で検索 → "コレ" → 下の紹介文を貼る」の3手だけにする。
使い方:
  1. 各コレクションの「楽天検索キーワード」で楽天市場/楽天ROOMを検索
  2. 「選定基準」に合う商品を3〜5点"コレ"（＝アフィリリンクが発行される）
  3. 直下の「貼るだけ紹介文」を貼る（【　】だけ差し替え）
  4. "コレ"して実際に発行された商品・URLは `rakuten_link_library.csv` に追記（network=rakuten・status=active。捏造リンク登録禁止）
厳守:
  - 価格・在庫・料率は変動するため**本文に金額は書かない**（`AFFILIATE_ARTICLE_STANDARDS.md §4.4`）。
  - 虚偽・誇大表現なし。使っていない商品を「使った」と書かない。
  - 投稿（コレ・公開）は**ゆうさんの手作業/承認**。ブラウザ自動操作は各媒体規約優先（`RIO_804`）。

## ③ 衛生・消耗品（最優先＝リピートが最も太い）

**楽天検索キーワード**: `施術ベッド ペーパー ロール` / `使い捨て タオル 業務用` / `フェイスガーゼ 美容 業務用` / `ニトリル手袋 パウダーフリー 箱` / `アルコール 除菌 業務用 詰め替え` / `ペーパータオル 業務用 まとめ` / `ゴミ袋 業務用 45L 半透明`

**選定基準**: ①1回で複数箱/ケース買いできる（まとめ買い＝単価↓）②レビュー多め＝現場実績 ③定番サイズ（特殊規格は避ける）④送料込み傾向。

**貼るだけ紹介文（テンプレC・リピート消耗品型）**
```
【消耗品名】は、切らすと現場が止まる。まとめ買いで単価も手間も下げておくのが正解です。
【商品】は【選ぶポイント1行：例 1ケースで◯週間もつ／厚手でズレにくい】。
補充の"買い忘れ"を無くすだけで、月末の慌てが減ります。
#サロン消耗品 #店舗備品 #開業準備
```
即投稿できる1点目（RKT-004・実在確認済み）:
```
業務用ペーパータオルは、切らすと受付も施術もいったん止まる地味に効く消耗品。
まとめ買いなら1枚あたりが下がって、補充頻度も減らせます。
「気づいたら残り1袋」を無くすだけで、地味にストレスが消えます。
#サロン消耗品 #店舗備品 #飲食店備品
```

## ① 開業でまず揃える店舗什器

**楽天検索キーワード**: `A型看板 木製 両面` / `ウェルカムボード 店舗` / `メニュースタンド 卓上 アクリル` / `什器 ラック 店舗 ディスプレイ` / `傘立て 業務用` / `玄関マット 業務用 店舗`

**選定基準**: ①屋外OK/耐久（看板・マット）②書き換え・差し替えができる（黒板・POP系）③組立が簡単。単価中〜高で"開業の最初の検索"を取る。

**貼るだけ紹介文（テンプレB・開業チェックリスト型）**
```
【業種】開業で"買い忘れがち"なもの、【商品】。
【なぜ必要か1行：例 入口の第一印象を作る／回遊動線を整える】。
あとで慌てて探すより、内装と一緒に押さえておくと楽です。
#開業準備 #【業種】開業 #店舗什器
```
即投稿できる1点目（RKT-002・A型看板／WP-004で確認済み）:
```
「店の前を素通りされる」を止めたいなら、まずA型看板から。
両面タイプは左右どちらから来た人にも見せられて、黒板タイプは書き換え自由。日替わりメニューや本日の空き状況をその場で更新できます。
屋外OKの木製スタンドは、置くだけで"やってる感"が出ます。
#店舗開業 #カフェ開業 #美容室開業
```

```
会計の【シーン：ピーク時】で効いてきます。
#店舗運営 #キャッシュレス #レジまわり
```

## ④ 集客・販促ツール

**楽天検索キーワード**: `のぼり旗 店舗 セット` / `卓上POP アクリルスタンド A6` / `ポスターフレーム A2 店舗` / `黒板 チョークマーカー 店舗` / `ショップカード スタンド`

**選定基準**: ①衝動買い単価（低〜中）×点数②"すぐ使える"完成品③張り替え/書き換えで長く使える。

**貼るだけ紹介文（テンプレA・悩み解決型）**
```
【悩み：例 もう一押し客単価を上げたい】なら、【商品】。
卓上に置くだけで【効果：おすすめ・限定を自然に伝えられる】。
"言わなくても伝わる"販促は、スタッフの負担も減らします。
#店舗集客 #販促グッズ #店舗運営
```
即投稿できる1点目（RKT-003・Instagram集客の教科書）:
```
「SNS集客、何から手をつければ…」の最初の1冊に。
店舗・サロン向けにInstagramの集客・販促を体系立てて解説してくれるので、自己流の遠回りを減らせます。
まず1冊で全体像を掴んでから、日々の投稿に落とし込むのがおすすめ。
#店舗集客 #Instagram集客 #販促
```

**選定基準**: ①スマホ/PCと繋がる②事務作業を"1手減らす"もの③物撮り・SNS運用に効く（本業のAI×SNSブランドへ接続）。
