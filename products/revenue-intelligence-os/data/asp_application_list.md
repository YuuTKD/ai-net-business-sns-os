## 申請優先順位ランキング（今すぐ動く順）

優先度は「①報酬の高さ × ②既存記事との親和性（=すぐ記事に差し込めるか）× ③店舗オーナーの需要」で判断。

### 優先度S（最優先・今日申請）

#### S-1. キャッシュレス決済端末（Square / STORES決済 / squareターミナル等）
- **なぜ最優先**: 店舗オーナーの需要が最も高く、POSレジ記事(WP-003)・ハブ記事に即差し込める。無料で始められる系が多く成果地点が軽い。
- **想定成果地点(目安)**: アカウント開設・端末申込。無料開設が成果地点なら承認率が上がりやすい。
- **報酬目安**: 決済系は1件あたり数千円規模の設定が多い（ASPにより大きく差。要管理画面確認）。
- **申請先ASP**: まず A8.net で「Square」「STORES 決済」「決済端末」を検索。無ければ もしも／バリューコマース系も候補。
- **申請メモ**: POSレジ記事と「レジ＋決済はセット」で内部リンクを組める。ハブ記事の「+α キャッシュレス決済端末」枠がそのまま受け皿。

#### S-2. 電子契約（freeeサイン / クラウドサイン 等）
- **なぜ最優先**: 労務・会計と親和。雇用契約・業務委託契約の電子化は店舗でも需要増。SaaS系で単価が比較的高い。
- **想定成果地点(目安)**: 無料プラン登録 or 有料申込。
- **報酬目安**: SaaS電子契約は1件あたり中〜高単価（数千円〜のことが多い。要確認）。
- **申請先ASP**: A8.net で「freeeサイン」「電子契約」を検索。freee系はA8取扱いが多い。もしもも確認。
- **申請メモ**: 既存の会計(freee含む)・労務記事と横断リンクしやすい。ハブ記事「+α 電子契約」枠の受け皿。

#### S-3. ネットショップ（Shopify / BASE / STORES ネットショップ）
- **なぜ最優先**: 物販・テイクアウト・オンライン販売を始める店舗の入口。Shopifyは有料課金で単価が高い傾向、BASE/STORESは無料開設で承認・成果が軽い。
- **想定成果地点(目安)**: 無料ショップ開設（BASE/STORES）／有料プラン契約（Shopify）。
- **報酬目安**: Shopify系は高単価設定が多い。BASE/STORESは開設ベースで中単価。要確認。
- **申請先ASP**: A8.net で「BASE」「STORES」「Shopify」を検索。もしもにもネットショップ系あり。
- **申請メモ**: ハブ記事「+α ネットショップ」枠＋独立記事化しやすい高需要ジャンル。

## 申請時の実務チェックリスト（ゆうさん用）

1. **ログイン先を確認**: A8.net（メディアID a24062165409）／もしもアフィリエイト／楽天アフィリエイト。新規ASPが必要なのはバリューコマース程度（決済・カード系で取扱いが厚い）。
2. **プログラム検索 → 提携申請**: 上記の商材名で検索し「提携申請する」を押す。
3. **審査待ちの管理**: 承認/却下/保留はASP管理画面で確認。**却下されたものは記事に商品名を出さない**（提携前に成果地点へ誘導しない）。
4. **承認されたら**: `affiliate_link_library_v2.csv` に新規行を追加（id採番: A8-004〜／MOSHIMO-004〜／新ASPは接頭辞を新設）。network_account_status=active・実発行URLのみ登録（手打ち/推測URL登録禁止）。
5. **報酬額の再確認**: このメモの金額は目安。記事に金額を書くときは、承認後の管理画面の最新値を確認してから記載する。
6. **記事への反映**: 承認された商材から、ハブ記事(WP-HUB)の「+α」枠・関連子記事へ実リンクを差し込む。
