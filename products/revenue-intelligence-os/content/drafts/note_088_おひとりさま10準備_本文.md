40代で独身の私が、"一人で老いる"覚悟を決めてから始めた10の準備

## はじめに ―― 「このまま、ひとりで年をとっていくんだな」と気づいた夜に

はじめまして。「一人で老いる準備ノート」の中の人です。顔も本名も出していません。40代の独身で、この先もたぶん、ひとりで生きていく。そう静かに腹をくくったところから、この準備を始めた、当事者のひとりです。

きっかけは、たいそうな出来事ではありませんでした。夜中にちょっと体調を崩して、「今もし動けなくなったら、誰が気づくんだろう」と思った。その一瞬です。パートナーがいるわけでもない。子どももいない。親も、いつまでも元気なわけじゃない。

そのとき胸に来たのは、寂しさよりも、もっと具体的な不安でした。**「老後」という言葉が、急に他人事じゃなくなった。**でも、何から手をつければいいのか、まるでわからなかった。

私はその夜から、少しずつ調べて、動いて、整えてきました。この記事は、そうやって一人の当事者が積み上げてきた「一人で老いるための、現実的な準備」を、10個にまとめたものです。専門家ではありません。だから、法律やお金や制度の細かい話は「ここは専門家に」と正直に線を引きます。そのぶん、「同じ立場の人間が、実際にどこから手をつけたか」は、包み隠さず書きます。

## 「老後の漠然とした不安」の正体

一人で年をとることの不安は、ぼんやりしていて、大きく見えます。でも、正体を分解すると、だいたいこの5つに収まります。

- **健康の不安**：倒れたとき、誰が気づくのか。入院や手術のとき、身元保証や手続きを誰がしてくれるのか。
- **お金の不安**：年金だけで足りるのか。いくら貯めればいいのか、見当もつかない。
- **住まいの不安**：高齢になったとき、ひとりで賃貸を借りられるのか。施設は。
- **つながりの不安**：孤独死。誰にも気づかれずに、というあの言葉。
- **手続きの不安**：親が亡くなったあと、自分に何かあったあと、後始末を誰が。

こうして並べると、少しだけ楽になりませんか。**「漠然とした不安」は、正体がわからないから大きく見えるだけ**です。ひとつずつ名前をつけて、ひとつずつ手を打てば、大きな塊が、小さな「やることリスト」に変わっていきます。

## この記事であなたが手にすること

この先で、私は自分が実際に取り組んできた10の準備を、こう書いていきます。

- 生活・お金・住まい・健康・つながり・手続き、6つの面をカバーする10項目
- 各項目に「なぜ必要か」「今日できる小さな一歩」「チェックリスト」
- 一人時間という不安を、"自由"に読み替えるための設計の考え方

ひとつ先に言っておきます。**全部を一気にやる必要はありません。**私も何年もかけて、ぽつぽつやってきました。今日は、リストを眺めて「あ、これならできそう」を一つ見つけるだけで十分です。

## 無料のヒント：不安は「見えない」から怖い。「書き出す」と半分になる

有料パートに入る前に、いちばん効いた一手を、ひとつだけ渡します。お金も専門知識もいりません。

それは、**「もし今、自分に何かあったら困ること」を、紙に全部書き出す**ことです。

倒れたら誰に連絡がいくのか。銀行口座やサブスクは。家の鍵は。ペットは。加入している保険は。親のこと。――頭の中でぐるぐる回っているうちは、不安は無限に大きく感じます。ところが紙に書き出すと、たいてい20行くらいで止まります。**無限だと思っていた不安が、"20行のやることリスト"だったと分かる。**これだけで、夜の重さが本当に変わります。

私は今でも、不安が膨らんだ夜はこれをやります。書き出して、「これは今日、これは来月、これは専門家に」と横に印をつける。それだけで、また眠れるようになります。

―― では、ここから、その20行を実際に埋めていく「10の準備」を、一枚ずつ描いていきましょう。

## 10の準備 ―― 一人で老いる自分への、静かな仕込み

ここからは、私が実際に手をつけてきた10項目です。順番に意味があります。「今すぐ命に関わる備え」から始めて、だんだん「長い目での設計」へ広げていく並びにしました。焦らず、上から気になったものだけでも大丈夫です。

### 準備1【健康・つながり】倒れても気づいてもらえる「緩い見守り」をつくる

**なぜ必要か。**一人暮らしでいちばん怖いのは、病気そのものより「気づかれないこと」です。倒れて動けないとき、数日誰にも気づかれない状態を避ける。これが土台になります。大げさな設備でなくていい。「異変が、そこそこ早く伝わる」経路を一本でも持つことです。

**今日できる一歩。**スマホの見守り機能を一つ確認する。iPhoneなら「緊急SOS」と「メディカルID」、Androidなら「緊急情報」に、連絡先とアレルギー・持病を登録しておく。倒れて発見されたとき、これが命綱になります。

**選択肢の例（自分に合うものを一つ)。**
- スマホの見守り・安否確認アプリ（一定時間反応がないと登録先へ通知）
- 家族や友人との「毎朝スタンプ1個」など、ゆるい生存確認の習慣
- 自治体・民間の見守りサービス、電気やガスの使用量で異変を知らせる系のサービス

**チェックリスト。**
- [ ] スマホの緊急情報・メディカルIDを登録した
- [ ] 「数日反応がなければ気づいてくれる」経路を一つ決めた
- [ ] その相手（またはサービス）に、実際に頼んだ・契約した

### 準備2【健康・手続き】もしもの入院に備えて「身元保証」の当てを考えておく

**なぜ必要か。**ひとりで入院・手術となったとき、多くの場面で「身元保証人」や「緊急連絡先」を求められます。ここで詰まる人が本当に多い。元気なうちに、当てをつけておくだけで安心感がまるで違います。

**ただし、ここは専門家・公的窓口の領域です。**身元保証・任意後見・死後事務などの契約は、内容も費用もサービスによって大きく異なり、トラブルも報告されています。金額や仕組みを私が断定することはしません。**まずは地域包括支援センターや自治体の福祉窓口、社会福祉協議会に「一人暮らしで身寄りが少ない。入院時の保証や将来の手続きが不安」と相談してください。**そこが、あなたの地域で使える制度や信頼できる窓口への入口になります。

**今日できる一歩。**「自分が住む市区町村名 + 地域包括支援センター」で検索して、最寄りの窓口の場所と電話番号をメモする。まだ電話しなくていい。「困ったらここ」を知っておくだけで、不安の質が変わります。

**チェックリスト。**
- [ ] 最寄りの地域包括支援センターの連絡先を控えた
- [ ] 入院時に緊急連絡先として書ける人・窓口を一つ思い浮かべた
- [ ] 保証・後見・死後事務の契約は「専門家に相談してから」と決めた

### 準備3【お金】老後資金を「貯める額」ではなく「逆算」で考える

**なぜ必要か。**「老後2000万円」みたいな数字に、私はずっと怯えていました。でも、あの手の金額は、家族構成も暮らし方も違う"誰か"の平均です。あなたに必要な額は、あなたの暮らしからしか出ません。**大事なのは「いくら貯めるか」より「毎月いくらで暮らせる自分か」を知ること**でした。

**逆算の考え方(あくまで発想の枠組みです)。**
1. 今の毎月の生活費を把握する（これが土台。ここが分からないと何も始まらない）
2. 老後に受け取れそうな公的年金の見込みを確認する
3. 「毎月の希望生活費 − 年金見込み」の差額が、自分で埋める必要のある部分

**ここは断定しません。**年金の見込み額は「ねんきんネット」や毎年届く「ねんきん定期便」で、あなた個人の数字を確認できます。運用・投資・保険で「増やす」話は、利回りも損失もあり、人によって最適解がまったく違います。**具体的な金額設計や商品選びは、必ずファイナンシャルプランナー（FP）など専門家に、自分の数字を持って相談してください。**ここでできるのは「怯えるのをやめて、自分の数字を見にいく」ところまでです。

**今日できる一歩。**先月のクレジットカードと銀行の引き落としを見て、「毎月ざっくりいくらで暮らしているか」を1つの数字にする。それだけ。

**チェックリスト。**
- [ ] 毎月の生活費のおおよその数字を出した
- [ ] ねんきん定期便／ねんきんネットで年金見込みを確認した（または確認予定日を決めた）
- [ ] 「増やす」話はFP等の専門家に相談する、と決めた

### 準備4【お金・手続き】お金と契約の「地図」を1枚つくる

**なぜ必要か。**銀行口座、証券、保険、サブスク、公共料金、ローン。ひとりだと、これらを把握しているのは自分だけです。自分が倒れたとき、亡くなったとき、これが散らばっていると、後始末する誰かが本当に困ります。そして生きている今の自分にとっても、「何にいくら払っているか」の見える化は、老後資金の第一歩になります。

**今日できる一歩。**紙かスマホのメモに、次を書き出す。「使っている銀行・証券・保険・毎月の固定費（サブスク含む)」。パスワードそのものは書かない。**「どこに何があるか」だけ**でいい。

**チェックリスト。**
- [ ] 金融機関・保険・固定費を一覧にした
- [ ] 使っていないサブスク・口座を1つ見つけた（ここで節約が生まれます）
- [ ] この一覧の"ありか"を、信頼できる人か、いざというとき見つかる場所に決めた

### 準備5【住まい】「最後まで住める住まい」を早めに考え始める

**なぜ必要か。**あまり語られませんが、高齢になると、一人だと賃貸契約を断られることがあります。保証や孤独死のリスクを大家さんが心配するためです。**選択肢は、元気で信用のあるうちほど広い。**だから「まだ先」と思う今こそ、考え始める価値があります。

**考えておく方向性（正解は人それぞれ）。**
- 今の住まいに、この先どのくらい住み続けられそうか
- 高齢者の賃貸を支える仕組み（家賃債務保証、住宅確保要配慮者向けの制度など）があること。詳細は自治体・社会福祉協議会・不動産の相談窓口へ。
- 持ち家なら、老後の維持費・バリアフリー・売却や住み替えの選択肢
- サービス付き高齢者向け住宅などの存在を「知っておく」だけでも安心材料になる

**制度や契約の細部は断定しません。**ここも地域包括支援センターや自治体の住宅相談が入口です。

**今日できる一歩。**「自分の住む自治体名 + 高齢者 住まい 相談」で検索し、相談窓口があることだけ確認しておく。

**チェックリスト。**
- [ ] 今の住まいに何歳くらいまで住む想定か、ざっくり考えた
- [ ] 高齢者向けの住まいの選択肢が「複数ある」と知った
- [ ] 住まいの相談窓口の存在を確認した

### 準備6【健康】「病院に一人で行ける自分」を保つ生活の土台

**なぜ必要か。**一人で老いるうえで、健康は最大の資産です。難しい健康法の話ではありません。**倒れる前に、"倒れにくい生活"の土台を持っておく。**そして、不調を我慢しない習慣を、今からつけておくことです。

**今日できる一歩。**かかりつけ医を一人決める（まだなければ、近所の内科を一つ思い浮かべる）。健康診断を「毎年受ける月」を決めてカレンダーに入れる。

**土台の考え方。**
- 睡眠・食事・少し歩く、の基本を崩さない。派手なことより継続。
- 不調を「歳のせい」で流さず、気になることは早めに医療機関へ。**体調の判断は自己流にせず、必ず医師に。**
- 常用薬・持病・アレルギーを、準備1のメディカルIDと連動させておく。

**チェックリスト。**
- [ ] かかりつけ医（候補でも可）を一つ決めた
- [ ] 次の健康診断の時期をカレンダーに入れた
- [ ] 常用薬・持病・アレルギーをメモ／メディカルIDに反映した

### 準備7【つながり】「孤独死」を避けるための、細く長い関係を育てる

**なぜ必要か。**一人で老いる不安のいちばん重い言葉が「孤独死」でしょう。でも、これは「たくさん友達を作らなきゃ」という話ではありません。私が求めているのは、太い友情ではなく、**"自分がしばらく姿を見せなかったら、あれ？と思ってくれる人が、数人いる"状態**です。それだけで、孤独死のリスクはぐっと下がります。

**今日できる一歩。**「最近、少し疎遠になっている人」に、用事のない短い連絡を一つ送る。近況スタンプでいい。関係は、細くても"回線が生きている"ことが大事です。

**細く長いつながりの例。**
- 定期的に顔を出せる場所（趣味の集まり、地域の活動、行きつけの店、オンラインの緩いコミュニティ)を一つ持つ
- SNSやメッセージで「生きてる報告」を軽くし合える相手を数人
- ご近所と、挨拶できる程度の関係。地域の見守りや民生委員の存在も知っておく

**チェックリスト。**
- [ ] 「姿を見せないと気づいてくれる人」が今、何人いるか数えた
- [ ] 定期的に緩くつながれる場を一つ持っている／探し始めた
- [ ] 今日、誰か一人に軽い連絡をした

### 準備8【手続き】親の「もしも」に備える ―― 親亡きあとの実務を先に知っておく

**なぜ必要か。**一人っ子や、きょうだいが遠方の独身にとって、親の介護と看取り、その後の手続きは、いずれ自分ひとりの肩にかかりがちです。悲しみの渦中で、初めての手続きに追われるのは本当に消耗します。**元気なうちに、親と少しずつ話し、実務の地図を持っておく。**これは親のためでもあり、そのあと一人になる自分のためでもあります。

**ここも専門家・窓口の領域です。**相続・遺言・不動産・年金の停止・各種名義変更などは、司法書士・弁護士・税理士・市区町村の窓口の担当です。手続きの数も期限もあり、私が断定できるものではありません。**「親が亡くなったあとの手続き」は自治体の窓口や司法書士会の相談などで、早めに全体像を掴んでおくのがおすすめです。**

**今日できる一歩(親が元気なうちに)。**重い話をいきなり切り出さなくていい。「もしものとき、加入してる保険とか、連絡すべき人とか、私、把握できてないなと思って」と、事務的な入口から一つだけ聞いてみる。

**知っておきたい実務の柱（詳細は専門家へ)。**
- 親の財産・保険・契約の「ありか」を、元気なうちに共有してもらう
- 遺言・相続の話は、こじれる前に専門家を交える選択肢がある
- 亡くなったあとの手続き（役所・年金・金融機関・不動産）は数が多く期限もある

**チェックリスト。**
- [ ] 親の保険・契約の「ありか」を、少しでも把握し始めた
- [ ] 相続・遺言・手続きの相談窓口（司法書士・弁護士・自治体）を知った
- [ ] 親と「事務的なこと」を話せる小さなきっかけを一つ作った

### 準備9【手続き】自分の「もしも」を、書いておく（エンディングノートの入口）

**なぜ必要か。**準備8の裏返しです。親の後始末で苦労するなら、自分のときは、後始末する誰かを少しでも楽にしたい。そして何より、**「自分の最後を、自分で決めておける」ことは、生きている今の安心そのもの**でした。遺言のような堅いものでなくていい。まずは気持ちのメモからで十分です。

**エンディングノートに書くことの例(市販・無料テンプレも多数あります)。**
- 加入している保険・口座・契約のありか（準備4の地図がそのまま活きる）
- 医療や延命について、自分の希望
- 連絡してほしい人、ペットのこと、デジタルデータやSNSの扱い
- 葬儀やお墓についての希望

**注意。**エンディングノートには法的な効力はありません。**財産の分け方など法的に有効にしたいことは「遺言」が必要で、これは形式が決まっています。相続・遺言の法的な部分は、必ず弁護士・司法書士など専門家に確認してください。**ノートは「気持ちと情報の整理」、遺言は「法的な意思表示」と役割が分かれます。

**今日できる一歩。**ノート1ページに「もし明日いなくなったら、これだけは伝えたい／困らせたくない」ことを3つ書く。それがエンディングノートの第一歩です。

**チェックリスト。**
- [ ] エンディングノート（市販・無料テンプレ・普通のノートで可）を一つ用意した
- [ ] 医療・連絡先・ペット・データのどれか一つを書いた
- [ ] 「法的なことは遺言＋専門家」と役割を理解した

### 準備10【設計】一人時間を「寂しさ」から「自由」に読み替える

**なぜ必要か。**ここまで9つ、守りの準備を並べてきました。でも、一人で老いることは、リスク管理だけの暗い話ではありません。**誰にも合わせなくていい時間、自分の裁量で使える人生の後半**でもあります。最後の準備は、いちばん大事かもしれない。「一人時間」を、耐えるものではなく、設計して味わうものに変える準備です。

**設計の考え方。**
- 「暇＝寂しい」ではなく「暇＝自分の裁量で埋められる余白」と捉え直す
- 一人でも満ちる時間（学び直し、趣味、体を動かす、静かな楽しみ)を、老いる前から育てておく。老後に急には作れません。
- 「誰かのため」だけでなく「自分が機嫌よくいられること」に、時間とお金を少し配分する
- 準備7の緩いつながりと、一人の自由。この二つのバランスが、一人で老いる幸福度をいちばん左右します。

**今日できる一歩。**「一人で、機嫌よくいられた時間」を最近から一つ思い出して、それを来週の予定に一つ入れる。守りだけじゃなく、この"攻めの一歩"を、必ず一つ持ってください。

**チェックリスト。**
- [ ] 一人でも満ちる時間・楽しみを、一つ言葉にできた
- [ ] それを来週の予定に一つ入れた
- [ ] 「一人時間＝自由」と読み替える視点を持てた
