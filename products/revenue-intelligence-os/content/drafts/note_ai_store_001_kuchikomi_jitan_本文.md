# 口コミ返信、1件5分かかっていませんか？──AIで「型」を作って時短する方法

## 想定媒体・アカウント
note「店主のAI時短メモ」（スモールビジネスカテゴリ）

## ターゲット
美容室・飲食店・整体院など、Googleビジネスプロフィールの口コミ返信を自分で書いている個人店オーナー

## 本文（下書き・無料公開想定）

口コミ返信、1件書くのに5分くらいかかっていませんか。

「ありがとうございます」から書き始めて、途中で「これテンプレっぽいな」と思い直して書き直して、結局10分近くかかる。忙しい合間にこれを月に20件、30件やっていたら、それだけで結構な時間です。

私も最初はそうでした。ですが、口コミ返信って実は「型」がかなり決まっています。

- 高評価 → 感謝 → 具体的な内容に触れる → 再来店の一言
- クレーム系 → 感謝 → お詫び → 改善の方向性 → 次への一言
- 事実と違う指摘 → 否定せず確認の姿勢を見せる

この「型」さえ決めてしまえば、あとは口コミの内容に合わせて中身を差し替えるだけです。ここでAI（ChatGPTやClaude）が便利に使えます。

私がやっている手順はシンプルです。

1. 口コミの本文をそのままAIに貼る
2. 「この口コミに、感謝→具体的な内容への言及→再来店の一言、という型で返信文を作って」と指示する
3. 出てきた文章を軽く自分の言葉に調整する

これだけで、1件あたりの時間は5分から1分程度まで縮みます。

ポイントは「AIに丸投げしない」ことです。AIが作った文章をそのまま貼ると、どこか他人行儀な文章になりがちです。最後に「自分が本当に言いそうな言葉」に1〜2箇所直すだけで、印象はかなり変わります。

### まず結論：この記事だけで得られるもの

- 状況別の返信テンプレート「本文そのもの」6パターン（コピペ可）

- AIにそのまま貼れるプロンプト3種類（状況別）

これを覚えてしまえば、口コミ返信にかかる時間は月換算で2〜3時間は変わってきます。

### 業種別トーンの違い（具体例つき）

同じ「ありがとうございます」でも、業種によって触れる場所を変えると印象が大きく変わります。

- 美容室：「担当した◯◯も大変喜んでおります」→ スタッフ個人への言及
- 飲食店：「またあの一品をお出しできる日を楽しみにしております」→ メニュー名への言及
- 整体院：「お身体の調子が少しでも楽になっていましたら幸いです」→ 体調への言及

丁寧さは同じでも、「何に触れるか」を変えるだけでテンプレっぽさが消えます。

### 状況別テンプレート本文（コピペ可・6パターン）

**1. 高評価（★5）への返信**
```
温かいクチコミをいただきありがとうございます。
スタッフの対応にご満足いただけたとのこと、本人をはじめスタッフ全員の
励みになります。お客様に「また来たい」と感じていただけるよう、
日々の接客を大切にしております。またのご来店をスタッフ一同
お待ちしております。
```

**2. ★3（中間評価）への返信**
```
貴重なご意見をありがとうございます。
◯◯の点について今後の参考にさせていただきます。
より満足いただけるお店を目指して、改善を重ねてまいります。
またのご来店をお待ちしております。
```

**3. 辛口だが具体的な指摘への返信**
```
貴重なご意見をありがとうございます。◯◯の点でご不便をおかけし
申し訳ございませんでした。いただいたご指摘は今後の改善の参考に
させていただきます。より良いお店づくりに努めてまいります。
```

**4. 事実と違う口コミへの返信**
```
この度はご来店ありがとうございます。詳しい状況を確認したいので、
よろしければ直接ご連絡いただけますでしょうか。［連絡先］まで
ご一報いただけますと幸いです。
```

**5. 店舗側に非があるケースの謝罪**
```
この度はご予約の確認不足によりご迷惑をおかけし、誠に申し訳
ございませんでした。原因を確認し、再発防止のため予約管理の
見直しを行っております。またお越しいただける機会がございましたら、
精一杯対応させていただきます。
```

**6. 繁忙期でまとめて返信するときの一言**
```
お返事が大変遅くなり申し訳ございません。
［以下、通常の返信テンプレートに接続］
```

### AIへの指示文（プロンプト）実例・3パターン

**パターンA：口コミ本文からそのまま生成**
```
以下の口コミに対して、感謝→具体的な内容への言及→再来店の一言、という
構成で200〜300文字の返信文を作ってください。業種は[美容室/飲食店/整体院]です。
口コミ本文：
[ここに口コミを貼る]
```

**パターンB：辛口・クレーム系の返信を作りたいとき**
```
以下の口コミ（クレーム・低評価）に対して、感謝→お詫び→改善の方向性→
次への一言、という構成で250〜350文字の返信文を作ってください。
反論や言い訳にならないよう注意してください。
口コミ本文：
[ここに口コミを貼る]
```

**パターンC：事実と違う口コミに冷静に対応したいとき**
```
以下の口コミの内容が事実と異なる可能性があります。感情的に否定せず、
事実確認を求める丁寧な返信文を150〜200文字で作ってください。
口コミ本文：
[ここに口コミを貼る]
```

### 実際のビフォーアフター

AIが最初に出してきた文章（そのまま）：
> 「この度はご来店いただき誠にありがとうございました。お客様からいただいたご意見を真摯に受け止め、今後のサービス向上に努めてまいります。」

自分の言葉に1箇所だけ直した後：
> 「ご来店ありがとうございました。いただいたご意見、次のメニュー改善にちゃんと活かします。」

──「真摯に受け止め」「サービス向上に努めてまいります」のような定型句を、実際に自分が使う言葉に変えるだけで、一気に「本人が書いた感じ」になります。
