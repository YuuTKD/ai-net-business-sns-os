# 口コミ返信、1件5分かかっていませんか？──AIで「型」を作って時短する方法

## 想定媒体・アカウント
note「店主のAI時短メモ」（スモールビジネスカテゴリ）

## ターゲット
美容室・飲食店・整体院など、Googleビジネスプロフィールの口コミ返信を自分で書いている個人店オーナー

## 本文（下書き・無料公開想定）

口コミ返信、1件書くのに5分くらいかかっていませんか。

「ありがとうございます」から書き始めて、途中で「これテンプレっぽいな」と思い直して書き直して、結局10分近くかかる。忙しい合間にこれを月に20件、30件やっていたら、それだけで結構な時間です。

私も最初はそうでした。ですが、口コミ返信って実は「型」がかなり決まっています。

- 高評価 → 感謝 → 具体的な内容に触れる → 再来店の一言
- クレーム系 → 感謝 → お詫び → 改善の方向性 → 次への一言
- 事実と違う指摘 → 否定せず確認の姿勢を見せる

この「型」さえ決めてしまえば、あとは口コミの内容に合わせて中身を差し替えるだけです。ここでAI（ChatGPTやClaude）が便利に使えます。

私がやっている手順はシンプルです。

1. 口コミの本文をそのままAIに貼る
2. 「この口コミに、感謝→具体的な内容への言及→再来店の一言、という型で返信文を作って」と指示する
3. 出てきた文章を軽く自分の言葉に調整する

これだけで、1件あたりの時間は5分から1分程度まで縮みます。

ポイントは「AIに丸投げしない」ことです。AIが作った文章をそのまま貼ると、どこか他人行儀な文章になりがちです。最後に「自分が本当に言いそうな言葉」に1〜2箇所直すだけで、印象はかなり変わります。

ここから先は、実際に私が使っている「型」を業種別・状況別に整理したテンプレート集と、AIへの指示文（プロンプト）の実例を掲載します。

### 業種別トーンの違い

- 美容室：担当スタッフへの言及を入れる
- 飲食店：メニュー名への言及を入れる
- 整体院：体調への言及を入れる

### 状況別テンプレート（抜粋）

1. 高評価（★5）への返信
2. ★3（中間評価）への返信
3. 辛口だが具体的な指摘への返信
4. 事実と違う口コミへの返信
5. 店舗側に非があるケースの謝罪
6. 繁忙期でまとめて返信するときの一言

### AIへの指示文（プロンプト）実例

```
以下の口コミに対して、感謝→具体的な内容への言及→再来店の一言、という
構成で200〜300文字の返信文を作ってください。業種は[美容室/飲食店/整体院]です。
口コミ本文：
[ここに口コミを貼る]
```

（実際の全テンプレート・プロンプト集は別売りの「口コミ返信テンプレート30本」でも提供しています）
