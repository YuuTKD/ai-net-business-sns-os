# 衝動買いが止まらない私が、"買う前に強制的に止まる"仕組みを作った話

はじめまして。「衝動買いを仕組みで止めるノート」の中の人です。

顔も本名も出していませんが、書いていることは全部、自分が実際にやってきたことです。少し前まで、私はどうしようもない衝動買い体質でした。

給料日の夜。仕事で嫌なことがあった日。なんとなく眠れない深夜。気づくとスマホでカートに商品を入れ、指がひとりでに購入ボタンを押している。翌朝、届いた箱を見て「なんでこれ買ったんだろう」と落ち込む。その繰り返しでした。

セール通知が来れば「今買わないと損」だと思い込み、ポイント◯倍デーには意味もなく買い足す。届いたときには少しだけ気分が上がるのに、数日後には興味を失う。クローゼットには一度も着ていない服、開けてもいないガジェット、読んでいない本が積み上がっていきました。

一番つらかったのは、「意志が弱い自分が悪い」と何度も自分を責めていたことです。

でも、たくさん失敗して分かったことがあります。

【意志の力で衝動買いを止めるのは、そもそも無理筋だった】

私が変われたのは、意志を強くしたからではありません。「意志に頼らなくても止まる仕組み」を先に作ったからです。

考えてみれば、通販サイトもクレジットカードも、フリマアプリも、「できるだけ速く・気持ちよく・迷わず買ってもらう」ために設計されています。ワンクリックで買える。カード情報は保存済み。おすすめが次々に出てくる。あちら側はプロが本気で「買わせる」仕組みを作っているのに、こちら側は自分の意志ひとつで戦っていた。勝てるわけがなかったんです。

だったら、こちらも「買いにくくする仕組み」を作ればいい。買うまでの手間をわざと増やして、頭が冷える時間を差し込む。それだけで、驚くほど衝動買いは減りました。

このノートでは、私が実際に使っている「買う前に強制的に止まる」仕組みを、そのまま真似できる形でお渡しします。

【このノートで得られること】

・衝動買いの「引き金」を自分で見つける方法
・カード情報やワンクリックを使って、決済にわざと摩擦を作る具体的な設定手順
・買う直前に自分へ突きつける「6つの質問リスト」（コピーして使えます）
・「今すぐ欲しい」を24時間やり過ごすための具体ルール
・ストレスで買いそうになったときの、お金を使わない代替行動リスト

どれも特別な道具もお金もいりません。今日、スマホの設定を少し変えるだけで始められます。

【無料でひとつだけ、本質のヒント】

有料部分に入る前に、一番効いたコツをひとつだけ先にお伝えします。それは、

「買わない努力」ではなく「買うまでを面倒にする」に発想を変えること。

たとえば、スマホやブラウザに保存しているクレジットカード情報を、今すぐ全部削除してみてください。これだけです。

次に何かを買おうとしたとき、あなたは16桁のカード番号を手で打ち込む羽目になります。この「ひと手間」の数十秒が、じつは魔法のように効きます。番号を打っている途中で「あれ、これ本当に要る?」と我に返れる瞬間が生まれるからです。

意志で我慢するのではなく、面倒くさくして止まる。この一点を体で覚えるだけでも、無駄遣いはかなり減るはずです。

ここまで読んで「もっと具体的に、仕組み全体を知りたい」と思ってくれた方へ。ここから先で、私が使っている止まる仕組みを、設定手順・テンプレートつきで丸ごとお渡しします。

――ここから有料――

ここからは、私が実際に組んでいる「買う前に強制的に止まる」仕組みを、順番にそのまま真似できる形で書いていきます。上から順にやれば、今日中に土台ができます。

【ステップ1 まず「引き金」を見える化する】

衝動買いには、ほぼ必ず引き金があります。まずは自分の引き金を知ることから始めます。難しく考えず、直近で「勢いで買ったもの」を3つ思い出して、次の3点をメモしてください。

・何を買ったか
・そのとき、どんな気分だったか（疲れ、退屈、イライラ、寂しさ、達成感、など）
・どこで見て買ったか（セール通知、SNS広告、深夜のスマホ、店頭、など）

これを3件書くと、自分のパターンが見えてきます。私の場合は「疲れて帰った深夜×スマホ×セール通知」が最強の組み合わせでした。引き金が分かれば、そこをピンポイントで潰せます。

【ステップ2 決済にわざと摩擦を作る（一番効く）】

ここが仕組みの心臓部です。買うまでの手間を、意図的に増やします。

やることは4つです。

1. 保存済みのカード情報を全部消す
スマホ、パソコンのブラウザ、通販アプリに保存された自動入力のカード情報を削除します。ブラウザの設定にある「お支払い方法」や「自動入力」の項目から消せます。次からは毎回手入力になり、その数十秒で頭が冷えます。

2. ワンクリック購入・かんたん決済をオフにする
Amazonなら「1-Click設定」を無効化、各アプリの「かんたん購入」「スピード決済」の類も全部オフに。買うまでに必ず数ステップを踏ませます。

3. アプリを消して、ブラウザ経由でしか買えなくする
通販・フリマアプリをホーム画面から削除します（アカウントは消さなくてOK）。買いたいときはブラウザで検索してログインし直す必要があり、この面倒さが効きます。

4. カートは「保管場所」にする
欲しくなったら買わずに、まずカートか「お気に入り」に入れるだけ。買うのは後日。カートを冷却期間の置き場として使います。

この4つだけで、「気づいたら買っていた」がほぼ起きなくなります。

【ステップ3 誘惑の入り口を閉じる】

そもそも誘惑が目に入らなければ、止まる回数を減らせます。

・通販アプリ、フリマアプリ、決済アプリの通知を全部オフにする
・セール・キャンペーンのメルマガを解除する
・SNSで「買いたくなるアカウント」をミュートかフォロー解除する
・ブラウザのブックマークから通販サイトを外す

「今だけ」「残りわずか」「本日限り」という言葉は、急がせて考える時間を奪うための仕掛けです。その言葉が目に入らない環境を作るほど、冷静でいられます。

【ステップ4 買う前の6つの質問リスト（コピーして使えます）】

「これは欲しい」と思ったとき、買う前に必ずこの6問に答えます。スマホのメモに貼り付けて、購入ボタンの前で開く運用にすると効きます。

1. これは「必要」か、それとも「今そういう気分」なだけか?
2. 同じ役割のものを、もう持っていないか?
3. 今日買わなかったら、1週間後も本当に欲しいと思っているか?
4. これを買うお金で、他にやりたかったことはないか?
5. 「安いから」「ポイントが付くから」が主な理由になっていないか?
6. 3か月後の自分は、この買い物を「よかった」と思っているか?

正直に答えると、半分以上は「別に要らない」に着地します。答えを書き出すこと自体が、頭を冷やす作業になります。

【ステップ5 24時間ルール（金額で線を引く）】

金額で機械的にルールを決めておくと、その場の判断がぶれません。私はこうしています。

・3000円未満 … その場で6つの質問に答えてから決める
・3000円以上1万円未満 … 最低24時間はカートに寝かせる。翌日まだ欲しければ検討
・1万円以上 … 3日間寝かせる。この間に一度、家族や信頼できる人に話してみる

寝かせている間に欲しい気持ちが消えたら、それは「本当に欲しいもの」ではなかったということ。時間は、衝動と必要を仕分けてくれる一番のフィルターです。

【ステップ6 ストレス買いの代替行動リスト】

衝動買いの多くは、モノが欲しいのではなく「今の気分をなんとかしたい」だけだったりします。買い物以外で気分を切り替える手を、前もって用意しておきます。

「買いたい」の波が来たら、まずこの中から1つやってみてください。

・15分だけ外を歩く
・シャワーを浴びる、顔を洗う
・コップ一杯の水を飲んで、5分だけ座って待つ
・欲しいものの写真だけ撮って「欲しいものリスト」に保存する（買わない）
・気持ちを3行だけメモに書き出す
・友だちや家族に「今ちょっと買いそう」とメッセージを送る

不思議なもので、波は10分から15分で引いていきます。その波さえやり過ごせれば、たいていの衝動買いは自然に消えます。

【私の1週間セットアップ手順（まとめ）】

上のステップを、無理なく始める順番に並べておきます。

・1日目 … カード情報を全削除、ワンクリック購入をオフ
・2日目 … 通販・フリマアプリを削除、通知を全部オフ
・3日目 … セールのメルマガ解除、SNSの「買いたくなる」発信元をミュート
・4日目 … 6つの質問リストをスマホのメモに保存
・5日目 … 24時間ルールの金額ラインを自分用に決める
・6日目 … 代替行動リストを、自分がやりやすい形に書き換える
・7日目 … 1週間を振り返り、効いた仕組みだけ残す

全部を完璧にやる必要はありません。効いたものだけ残して、生活に馴染ませていけば十分です。

【最後に】

私はこの仕組みで、衝動買いをかなり減らせました。ゼロにはなっていませんが、それでいいと思っています。大事なのは「たまに失敗しても、また仕組みに戻ってこられる」こと。自分を責める必要はありません。うまくいかない日があっても、それはあなたの意志が弱いからではなく、まだ仕組みが体に馴染んでいないだけです。

そして、これはとても大切なことなので最後に書いておきます。

もし買い物のコントロールが効かず、生活費や貯金を大きく崩している、借金をしてまで買ってしまう、やめたいのにどうしてもやめられずつらい――そう感じるなら、それは意志の問題ではなく、専門家の力を借りたほうがよいサインかもしれません。

・気持ちや行動のコントロールがつらいとき … お住まいの地域の精神保健福祉センターや、心療内科・精神科などの医療機関に相談できます。
・すでに借金や支払いで困っているとき … 借金や債務整理は、弁護士・法テラス・お近くの消費生活センターなどの専門窓口で相談できます（お金の問題は、早めに専門家に相談するほど選べる手が多くなります）。

このノートは、あくまで日々のちょっとした無駄遣いを減らすための工夫をまとめたものです。医療的な診断や治療を目的としたものではなく、効果を保証するものでもありません。ご自身の状況に合わせて、無理のない範囲で取り入れてもらえたらうれしいです。
